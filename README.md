# Coffee Shop Website

A single-page, responsive, accessible, and SEO-friendly coffee shop website built with HTML5, CSS3, and Vanilla JavaScript.

## Features

- **Responsive Design**: Works on mobile, tablet, and desktop devices
- **Accessibility**: WCAG 2.1 AA compliant with semantic HTML, ARIA labels, and keyboard navigation
- **SEO Optimized**: Includes meta tags, Open Graph, schema.org LocalBusiness markup
- **Functional Contact Form**: Client-side validation with visual feedback
- **Interactive Elements**: Smooth scrolling, mobile menu toggle
- **Google Maps Integration**: Embedded location map

## Sections

1. Hero - Shop introduction with call-to-action
2. Menu - Espresso, latte, and pastries with prices
3. Hours - Business hours display
4. Location - Embedded Google Map
5. Contact - Form with validation
6. Footer - Social links and copyright

## Tech Stack

- HTML5 (Semantic)
- CSS3 (Flexbox/Grid, CSS Variables)
- Vanilla JavaScript (Form validation, DOM manipulation)
- Google Maps Embed API

## Deployment

This site is deployed to Vercel and can be accessed at: [https://coffee-shop-website.vercel.app](https://coffee-shop-website.vercel.app)

## Development

To run locally:
1. Clone the repository
2. Open `index.html` in your browser
3. No build process required - pure static site
